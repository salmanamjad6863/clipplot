# Footage for the render worker

Put **rights-safe** background footage here, one folder per game slug:

```
worker/footage/gta-6/my-gameplay-01.mp4
worker/footage/gta-6/official-trailer-3.mp4
worker/footage/minecraft/...
```

Use only footage you're allowed to use: your own gameplay captures, official publisher
trailers (short excerpts with your commentary on top), or clips you have written permission for.
Never put downloaded videos from other creators here.

If a game's folder is empty, the worker uses an animated gradient background instead.
Videos in this folder are git-ignored.
